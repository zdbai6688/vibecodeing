## 1. 文档说明

本 PRD 针对 UOS 速记**桌面模式主界面**（三栏布局：左侧导航 / 中间列表 / 右侧编辑器）做整体产品规划，解决当前"逐步迭代、缺乏整体规划"的问题。规划范围覆盖：产品定位、信息架构、交互流程、视觉规范、验收清单。

配套交付物（另立子任务）：
- 交互原型（线框图）→ UI/UX 设计师
- 视觉规范稿 → UI/UX 设计师
- 功能验收清单执行 → 测试工程师

## 2. 产品定位梳理

### 2.1 定位

**UOS 速记 = 统信 UOS 原生的办公信息中枢**：以「快速捕捉 → 智能整理 → 高效输出」为闭环，整合笔记、待办、会议速记、AI 助手四大核心能力。桌面模式是用户最主要的深度工作场所，承担"整理、编辑、回顾、输出"职能；快速录入（紧凑窗口）承担"捕捉"职能。

### 2.2 核心用户场景（P0）

| 场景 | 用户 | 核心诉求 | 桌面模式关键路径 |
|------|------|---------|----------------|
| 会议记录 | 政企办公人员 | 录音→转写→纪要→待办 | 会议页全流程 + 结果沉淀到笔记/待办 |
| 工作备忘/待办跟踪 | 政企办公人员 | 快速记录、到期提醒 | 统一新建入口 + 待办视图分组 + 角标 |
| 灵感/技术笔记 | 开发者/文字工作者 | Markdown、快速检索 | 编辑器双模式 + 全文搜索 + 标签 |
| 快速捕捉后整理 | 所有用户 | 捕捉内容回到主界面整理 | 紧凑窗口 → 主界面列表实时衔接 |

P1/P2 场景：课堂录音总结（教育）、实时字幕（听障）、智能周报（周回顾）。

### 2.3 与移动端/Web 端的功能边界

| 维度 | 桌面模式（本 PRD 范围） | 移动端/Web（后续规划，不在本期） |
|------|----------------------|-------------------------------|
| 定位 | 深度编辑、管理、会议全流程 | 随手记录、查看、轻编辑 |
| 能力 | 全部核心功能 + 系统集成（托盘/全局快捷键/便签） | 核心查看 + 新建 + 同步读取 |
| 数据 | 本地 SQLite 为主，后续可选云同步 | 依赖同步服务 |

> 本期只做桌面模式，移动端/Web 仅定义边界（不做实现），确保架构预留扩展。

## 3. 信息架构（桌面模式三栏布局）

### 3.1 三栏布局结构

```
┌────────────────────────────────────────────────────────────────────┐
│ 标题栏：应用名 · 全局搜索 · 新建(+) · 视图切换 · 设置 · 窗口控制      │
├──────────┬──────────────────────────────┬──────────────────────────┤
│ 左栏 导航 │ 中栏 列表/工作区              │ 右栏 编辑器/详情          │
│          │                              │                          │
│ 全部笔记  │ · 笔记列表（标题/摘要/时间/标签)│ · 富文本/Markdown 编辑器  │
│ 待办      │ · 待办列表（分组：今日/本周/逾期)│ · 待办详情卡片           │
│ 会议      │ · 会议列表（录音/转写/纪要)     │ · 会议录音+转写+纪要      │
│ 周报      │ · 周视图                      │ · 周报编辑/生成           │
│ 最近删除  │                              │                          │
│ ─────────│                              │                          │
│ 标签筛选  │                              │                          │
│ 归档      │                              │                          │
├──────────┴──────────────────────────────┴──────────────────────────┤
│ 状态栏（可选）：笔记数 · 待办未完成数 · 数据本地提示                   │
└────────────────────────────────────────────────────────────────────┘
```

### 3.2 侧边导航分组

建议分三组（自上而下），并给出隐藏/折叠规则：

1. **核心功能**（始终显示）
   - 全部笔记、待办、会议、周报
   - 规则：点击切换中栏内容，当前项高亮；待办在"今日有未完成"时显示角标
2. **标签筛选**（可折叠）
   - 标签列表 + "新建标签"
   - 规则：点击按标签过滤全部笔记/待办；标签可重命名/删除；空标签自动隐藏
3. **归档/系统**（置于底部或分隔线以下）
   - 最近删除、设置入口（或放标题栏）
   - 规则：最近删除不常驻计数，仅在非空时显示数量角标

现状（源码 `sidebarwidget.cpp`，固定 200px）为功能堆叠式导航，无分组与折叠；本规划要求按上述分组重构导航层级，保留现有切换能力。

### 3.3 角标数字含义与更新规则

| 角标位置 | 含义 | 更新时机 |
|---------|------|---------|
| 待办 | 未完成待办数（默认显示全部未完成；可配置为仅今日） | 增删改/完成状态变化时实时刷新 |
| 会议 | 进行中录音数（红点） | 录音开始/结束 |
| 最近删除 | 回收站条目数 | 进入回收站/恢复/清空时 |
| 标签（可选） | 该标签下条目数 | 条目增删改时 |

规则：角标 ≤ 99 显示数字，> 99 显示 "99+"；点击导航进入对应视图后，角标不消失（数量型角标），仅"会议进行中"红点在进入会议视图后改为常规标识。

### 3.4 设置页面功能分区

| 分区 | 内容 |
|------|------|
| 常规 | 开机自启、托盘常驻、语言、数据目录、备份/恢复 |
| 快捷键 | 快速录入（默认 Alt+Space，见 §5.3 决策项）、新建笔记、新建待办、便签模式切换 |
| 语音/AI | ASR 引擎选择（本地 Whisper / 在线）、LLM API 配置（Key 加密存储）、转写语言 |
| 外观 | 主题跟随/浅色/深色、界面缩放、中栏宽度记忆 |
| 关于 | 版本、更新、许可证、开源信息 |

## 4. 交互流程设计

### 4.1 统一新建入口

**原则：一个主入口 + 快捷键 + 全局捕捉，三类路径并存但职责清晰。**

1. **主入口（标题栏"+"按钮）**：按当前上下文新建——
   - 在笔记视图 → 新建笔记
   - 在待办视图 → 新建待办
   - 在会议视图 → 新建会议
   - 在标签筛选下 → 新建笔记并自动带上该标签
2. **快捷键**：Ctrl+N 新建笔记；Ctrl+Shift+N 新建待办（设置中可改）
3. **全局捕捉**：Alt+Space 快速录入窗口，不经过主界面（见 §5.3）

现状存在多入口（各视图各自的新建按钮 + 全局快捷键 + 托盘菜单），需收敛为上述统一规则；视图内保留"就近新建"快捷按钮，但视觉与行为一致（同一图标/位置规范）。

### 4.2 笔记 ⇔ 待办转换

- 笔记 → 待办：编辑器工具栏"转为待办"按钮 + 列表右键菜单。转换后：原笔记内容作为待办"备注"保留，标题沿用首行，可补截止日期/优先级；转换可撤销（保留原笔记在回收站或可回退）。
- 待办 → 笔记：待办卡片右键"转为笔记"。转换后生成一篇以待办标题为标题的笔记，正文含备注内容，原待办标记为已完成并从待办列表隐藏。
- 视觉提示：转换操作前弹确认（如笔记含图片/长文，提示"将作为附件/正文保留"）。

### 4.3 快速录入与主界面的衔接

- 全局唤起紧凑窗口（无边框、置顶、聚焦输入框）。
- 保存后：数据落库 → 主界面对应列表实时刷新（不重启、无感知）→ 新条目在列表顶部并高亮 2 秒。
- 点击新条目：打开完整编辑器（Ctrl+Enter 在窗口内直接跳到主界面编辑该条）。
- 托盘菜单"最近笔记"点击同样进入主界面对应条目。
- 主界面收到全局快捷键时：若窗口最小化/隐藏则恢复并聚焦快速窗口；避免重复实例（单实例）。

### 4.4 会议：录音 → 转写 → 纪要 完整流程

```
新建会议 → 录音（开始/暂停/继续/停止）→ 实时转写
  → 停止后一键"生成纪要"（AI 摘要：主题/时间/参与人/要点/结论）
  → 纪要可编辑、可导出（Markdown/TXT/PDF）、可"提取待办"
  → 会议记录进入会议列表，可回放录音（时间戳跳转）
```

- 转写中可随时打标记（时间戳），点击时间戳跳转录音位置。
- 生成纪要前若转写文本为空，提示并引导重录或手动输入。
- "提取待办"把纪要中的行动项写入待办，并在纪要中保留来源会议链接。

### 4.5 空状态/引导状态文案（首版定稿）

| 场景 | 文案（示例，最终以视觉稿为准） |
|------|------------------------------|
| 全部笔记为空 | "还没有笔记，点击「+ 新建笔记」或按 Ctrl+N 开始记录" |
| 待办为空 | "没有待办事项，点击「+ 新建待办」，或从会议纪要中提取" |
| 搜索结果为空 | "没有找到与「{关键词}」相关的内容" |
| 会议列表为空 | "还没有会议记录，点击「+ 新建会议」开始录音转写" |
| 标签下为空 | "该标签下暂无内容" |
| 最近删除为空 | "删除的笔记会在这里保留，可随时恢复" |
| 编辑器未选中 | "选择左侧笔记开始编辑，或点击「+」新建" |

文案要求：友好、有下一步引导，不做技术化表述。

## 5. 视觉规范

### 5.1 视觉基准

**以统信 DTK6 设计规范为第一基准（UOS 原生），对齐麒麟速记的信息架构与交互习惯，不照搬其视觉皮肤。** 理由：目标平台是 UOS，DTK6 已随系统提供主题、字体、控件与窗口装饰，直接套用可获得最佳原生体验与最小维护成本；麒麟速记的"左栏 + 内容区 + 编辑器"布局已作为参考（详见《麒麟速记分析报告》7.1）。

| 维度 | 本产品规范 | 麒麟速记（参考） |
|------|-----------|----------------|
| 布局骨架 | 三栏（导航/列表/编辑器） | 左栏 + 主内容 + 右编辑器（同构） |
| 主题 | 跟随系统深浅色（DTK6 token） | 深浅色 token 切换 |
| 风格 | 扁平、克制的原生控件 | 毛玻璃 + 原生控件 |
| 差异点 | 更强调内容区可读性与中栏信息密度 | 视觉装饰偏重 |

### 5.2 三栏宽度比例（验证建议）

| 栏 | 默认宽度 | 可调范围 | 说明 |
|----|---------|---------|------|
| 左导航 | 200px | 200px ↔ 64px（图标折叠） | 折叠后仅图标 + 角标 |
| 中列表 | 300px | 240px ↔ 400px | 支持拖拽分隔条调整 |
| 右编辑器 | 剩余自适应 | 最小 480px | 低于 480px 时提示或压缩中栏 |
| 窗口 | — | 最小 1100×700 | 低于最小尺寸时隐藏状态栏/折叠左栏 |

验证项：默认比例（200/300/剩余）在 1366×768 与 1920×1080 下均满足编辑器 ≥ 480px；若屏幕过窄，优先折叠左栏而非压缩编辑器。

### 5.3 深浅色主题

- 跟随系统（默认）：DTK6 自动切换，业务组件必须使用语义色 token，禁止写死明暗值。
- 手动覆盖：设置中提供"浅色/深色/跟随系统"三态。
- 验收：所有页面在两种主题下对比度 ≥ WCAG AA（正文 ≥ 4.5:1）。

### 5.4 图标/按钮/卡片统一规范

| 元素 | 规范 |
|------|------|
| 图标 | 使用 deepin 图标主题（大小 16/20/24/32），线性风格、1.5px 描边，禁用混用 |
| 主按钮 | 圆角 8px，主色填充（默认主题色），悬停/按下有状态反馈 |
| 次级按钮 | 边框 + 透明底，主色文字 |
| 卡片 | 列表卡片：圆角 8px、1px 边框（分隔线色）、悬停轻微阴影 + 背景加深；选中态主色描边 |
| 间距 | 4/8/12/16/24 步进体系，栏间距 12px，卡片内边距 12px |
| 字体 | 系统字体栈（思源黑体/Noto Sans CJK），正文 14px、标题 16px、辅助 12px |

## 8. 待确认决策项

1. 快速录入全局快捷键：需求书写 Alt+Shift+S；当前实现为 Alt+Space（与麒麟速记一致）。**建议保留 Alt+Space**（对齐竞品、肌肉记忆成本低），如 UOS 桌面环境存在冲突再改，最终以用户确认为准。
2. 标签是否参与"全部笔记"混排：建议标签仅作筛选，不作为独立顶级导航。
3. 云同步本期不做，仅预留接口（边界见 §2.3）。
