## 4. 数据库设计

### 4.1 数据文件位置

| 文件 | 路径 | 说明 |
|------|------|------|
| 主数据库 | `~/.config/kylin-note-conf/kylin-note.db` | SQLite 3, 32 KB |

### 4.2 数据库完整性检查流程

应用启动时执行:
```
1. PRAGMA integrity_check → 验证数据库完整性
2. 检查 notes_todos 表是否存在
3. 检查 deleted_notes_todos 表是否存在
4. 检查 MEETINGRECORD 表是否存在
5. 清理过期删除记录
```

### 4.3 表结构 DDL

#### notes_todos（笔记/待办主表）

```sql
CREATE TABLE IF NOT EXISTS notes_todos (
    id                     INTEGER PRIMARY KEY AUTOINCREMENT,
    title                  TEXT,
    tag                    TEXT,
    priority               INTEGER NOT NULL DEFAULT (0),
    is_todo                BOOLEAN DEFAULT (0),
    creation_datetime      INTEGER NOT NULL DEFAULT (0),
    modification_datetime  INTEGER NOT NULL DEFAULT (0),
    deletion_datetime      INTEGER NOT NULL DEFAULT (0),
    start_datetime         INTEGER NOT NULL DEFAULT (0),
    end_datetime           INTEGER NOT NULL DEFAULT (0),
    completion_datetime    INTEGER NOT NULL DEFAULT (0),
    short_content          TEXT,
    rich_content           TEXT,
    plain_content          TEXT
);
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER PK | 自增主键 |
| `title` | TEXT | 标题 |
| `tag` | TEXT | 标签名 |
| `priority` | INTEGER | 优先级 (0=无, >=1 分等级) |
| `is_todo` | BOOLEAN | 0=笔记, 1=待办 |
| `creation_datetime` | INTEGER | 创建时间 (Unix timestamp) |
| `modification_datetime` | INTEGER | 最后修改时间 |
| `deletion_datetime` | INTEGER | 删除时间 (0=未删除) |
| `start_datetime` | INTEGER | 待办开始时间 (0=未设置) |
| `end_datetime` | INTEGER | 待办截止时间 (0=未设置) |

| `short_content` | TEXT | 内容摘要 (列表显示用) |
| `rich_content` | TEXT | Qt RichText HTML 4.0 格式完整内容 |
| `plain_content` | TEXT | 纯文本内容 (搜索用) |

### 4.5 运行时SQL操作清单

**统计查询**:
```sql
SELECT COUNT(*) FROM notes_todos WHERE is_todo = 0;                              -- 笔记总数
SELECT COUNT(*) FROM notes_todos WHERE is_todo = 1;                              -- 待办总数
SELECT COUNT(*) FROM notes_todos WHERE is_todo = 1 AND completion_datetime = 0;  -- 未完成待办
SELECT COUNT(*) FROM sqlite_master WHERE type='table' AND name='notes_todos';     -- 检查主表存在
SELECT COUNT(*) FROM sqlite_master WHERE type='table' AND name='deleted_notes_todos'; -- 检查回收站表存在
```

**数据操作**:
```sql
SELECT * FROM notes_todos;                                                        -- 全量加载
SELECT * FROM deleted_notes_todos;                                                -- 回收站加载

INSERT INTO notes_todos (...) VALUES (...);                                       -- 新建
INSERT INTO deleted_notes_todos (...) VALUES (...);                               -- 删除 (移到回收站)

DELETE FROM notes_todos WHERE id = ?;                                             -- 从主表移除
DELETE FROM deleted_notes_todos WHERE id = ?;                                     -- 永久删除
DELETE FROM deleted_notes_todos WHERE deletion_datetime < ?;                      -- 自动清理过期

INSERT INTO notes_todos (...) SELECT ... FROM deleted_notes_todos WHERE id = ?;   -- 恢复单条
INSERT INTO notes_todos (...) SELECT ... FROM deleted_notes_todos;                -- 全部恢复

UPDATE notes_todos SET tag = :newTag WHERE id IN (...);                           -- 标签改名
UPDATE deleted_notes_todos SET tag = :newTag WHERE id IN (...);                   -- 回收站标签同步
```

## 5. 功能模块详解

### 5.1 快速录入

**定位**: 全局最快速的笔记入口

| 属性 | 详情 |
|------|------|
| **全局快捷键** | `Alt + Space` (KGlobalAccel 注册) |
| **触发方式** | ① 快捷键 `Alt+Space` ② 托盘 "+" 按钮 ③ 主窗口 "+" 按钮 |
| **输入方式** | 键盘文本输入 + 语音输入 (流式识别) |
| **录入选项** | 标签选择、日期选择（设置后自动转为待办）、优先级选择 |
| **窗口类型** | 弹出式独立窗口，支持多屏定位 |
| **核心组件** | `QuickEntryWidget` (libQuickEntry.so) |

**工作流程**:
```
全局快捷键 Alt+Space
  → QuickEntryWidget 弹出
    → 用户选择输入方式:
      ├── 键盘输入文本
      └── 点击麦克风 → 语音识别 SDK 初始化
            → onSpeechIntermediate (中间结果流式回显)
            → onSpeechFinal (最终确认结果)
    → 可选: 选择标签 / 日期 / 优先级
    → 点击保存
      → 如果有日期: is_todo=1, 创建待办
      → 如果无日期: is_todo=0, 创建笔记
    → 刷新主界面列表和托盘列表
```

**语音输入安全检查**:
- 未配置模型 → 弹出提示，可跳转系统设置
- 无AI子系统 → 禁用语音按钮
- 麦克风被占用 → 提示关闭其他应用
- 网络异常 → 弹窗提示 (不阻塞输入)
- 语音输入过程中阻止键盘输入

**关键信号/槽**:
```
sigShowQuickEntry()                    → 显示快速录入
slotSpeechIntermediateResult(char*)    → 中间语音结果
slotSpeechFinalResult(char*)           → 最终语音结果
slotWarning(QString)                   → 警告提示
slotSetupSpeech()                      → 跳转设置
slotNoAISub()                          → 无AI子系统处理
```
