## 应用描述（中文）

### 短描述（80字以内）
UOS速记是统信UOS原生的办公信息中枢，集笔记管理、待办跟踪、语音速记、AI会议助手于一体，让信息管理更高效。

### 长描述（300字以内）
UOS速记是统信UOS原生的办公信息中枢，集笔记管理、待办跟踪、语音速记、AI会议助手于一体。通过 `Alt+Space` 全局快捷键随时捕捉灵感，支持富文本/Markdown 双模笔记、语音实时转文字、AI 智能摘要，待办日历视图与 AI 周报让信息管理更高效。

**核心功能：**
- 📝 **笔记管理**：Markdown/富文本双模编辑，标签分类，快速搜索，文件夹管理
- ✅ **待办管理**：截止日期、优先级、完成状态，今日/本周/逾期自动分组看板，日历网格视图 + 拖拽改期
- ⚡ **快速捕捉**：Alt+Space 全局快捷键（可自定义），紧凑便签贴边隐藏 + 多窗口，随时随地记录灵感
- 🎤 **语音速记**：录音 + 实时转写，支持离线转写（Whisper.cpp）
- 🤖 **AI 会议助手**：录音转文字、AI 摘要生成、待办自动提取
- 📊 **智能周报**：周视图每日待办 + 标签维度统计，AI 辅助生成周报
- 🌙 **深色主题**：完整适配系统深浅色，跟随 DPalette 无硬编码色残留
- 🌐 **国际化**：支持中英文界面切换
- ♻️ **回收站增强**：批量恢复/永久删除/搜索
- 🔒 **隐私优先**：数据 100% 本地存储，无需注册账号

## 应用描述（English）

### Short Description
UOS Shorthand is a native office information hub for UOS, integrating note management, todo tracking, voice transcription, and AI meeting assistant.

### Long Description
UOS Shorthand is a lightweight office information hub for UOS desktop. It integrates note management, todo tracking, voice transcription, and AI meeting assistant into one seamless experience.

**Key Features:**
- 📝 Note Management: Markdown/Rich text editor, tags, search, folders
- ✅ Todo Management: Due dates, priority, kanban view (Today/Week/Overdue), calendar grid with drag-to-reschedule
- ⚡ Quick Capture: Customizable Alt+Space global hotkey, compact sticky notes with edge-dock and multi-window support
- 🎤 Voice Transcription: Recording + real-time transcription with offline support
- 🤖 AI Meeting Assistant: Transcription, AI summary, todo extraction
- 📊 Smart Weekly Report: Daily todos with tag statistics + AI-assisted generation
- 🌙 Dark Theme: Full system theme adaptation via DPalette
- 🌐 i18n: Chinese/English UI switching
- ♻️ Enhanced Trash: Batch restore/delete/search
- 🔒 Privacy First: 100% local storage, no account required
