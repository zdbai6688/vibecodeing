## 紧凑模式使用说明

新的敬业签风格紧凑模式已实现：

```
快捷键 Alt+Space
┌──────────────────────┐
│ □                  ✕ │  ← 展开 / 关闭
│                      │
│ 快速记录...           │  ← 单行输入
│                      │
│ 🎤 📷          保存  │  ← 语音/截图/保存
└──────────────────────┘
         ↓ 点击「□」
┌──────────────────────────────┐
│ 缩小          Enter保存...   │
├──────────────────────────────┤
│                              │
│      完整输入模式             │
│                              │
├──────────────────────────────┤
│ 🎤 语音  📷 截图    取消 保存 │
└──────────────────────────────┘
```

- **紧凑模式**：280x160 浮动小窗口，贴边显示，快速输入 + 保存
- **完整模式**：520x260 全功能录入窗口，支持标签、优先级、语音、截图
- 按 `Enter` 保存，`Ctrl+Enter` 换行，`Esc` 关闭
