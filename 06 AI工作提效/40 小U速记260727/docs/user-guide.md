## 1. 安装与启动

### 系统要求
- 操作系统：统信 UOS 1070 及以上版本
- 内存：建议 2GB 以上
- 磁盘空间：100MB

### 安装方式

**方式一：UOS 应用商店**
1. 打开 UOS 应用商店
2. 搜索"UOS速记"
3. 点击"安装"

**方式二：玲珑包安装**
```bash
ll-cli install uos-shorthand
```

**方式三：deb 包安装**
```bash
sudo apt install ./uos-shorthand_1.0.0-1_amd64.deb
```

### 启动
- 在启动器中搜索"UOS速记"并点击图标
- 或在终端运行 `uos-shorthand`

## 2. 快速开始

### 创建第一条笔记
1. 启动 UOS 速记
2. 点击工具栏的「新建笔记」按钮，或按 `Ctrl+N`
3. 输入标题和内容
4. 点击「保存」或按 `Ctrl+S`

### 使用快速录入
1. 在任何应用中按 `Alt+Space`
2. 在弹出的快速录入窗口中输入文字
3. 按 `Enter` 保存

### 创建待办事项
1. 点击侧边栏的「待办事项」
2. 点击「新建待办」（在待办看板中）
3. 设置标题、截止日期和优先级

## 3. 笔记管理

### 创建笔记
- 点击工具栏「新建笔记」按钮
- 使用快捷键 `Ctrl+N`
- 通过快速录入窗口 `Alt+Space`

### 编辑笔记
- **Markdown 编辑**：支持标题、粗体、斜体、列表、代码块、链接等语法
- **工具栏**：使用 B/I/U/H1/H2/H3/列表/代码块/链接 按钮快速插入 Markdown 语法
- **预览模式**：点击「预览」按钮查看渲染效果

### 标签管理
- 在笔记编辑器中，从下拉框选择标签
- 在快速录入中使用 `#标签名` 语法自动创建标签

### 搜索笔记
- 使用顶部搜索框输入关键词
- 支持全文搜索（标题+内容）

### 回收站
- 删除的笔记先进入回收站
- 可在回收站中恢复或永久删除

## 4. 待办管理

### 创建待办
- 在笔记编辑器中点击「转为待办」按钮
- 在快速录入中使用 `!高/中/低` 语法

### 待办看板
待办事项自动分为四个分组：
- **今日待办**：截止日期为今天的待办
- **逾期待办**：已过截止日期的待办（红色高亮）
- **本周待办**：本周内到期的待办
- **已完成**：已勾选完成的待办

### 完成待办
- 点击待办项前的复选框即可标记完成
- 已完成待办自动移至「已完成」分组

### 笔记⇔待办互转
- 在笔记编辑器中点击「转为待办」按钮
- 待办也可在编辑器中点击「转为笔记」

## 5. 快速录入

### 全局快捷键
- `Alt+Space`：在任何界面唤起快速录入窗口

### 输入方式
- **文字输入**：直接输入笔记内容
- **语音输入**：点击「🎤 语音」按钮，选择录音文件导入
- **截图录入**：点击「📷 截图」按钮，截图后自动插入

### 快捷语法
- `#标签名`：保存时自动创建并关联标签
- `!高/!中/!低`：设置优先级（高/中/低）

### 快捷键
- `Enter`：保存并关闭
- `Esc`：取消并关闭
- `Ctrl+Enter`：换行

## 6. 会议记录

### 创建会议
1. 点击侧边栏「会议记录」
2. 点击「新建会议」

### 录音
系统使用 GStreamer 录音引擎，支持：
- 开始/暂停/继续/停止录音
- 录音文件保存为 WAV 格式
- 录音文件自动保存在应用数据目录

### 转写
- 转写内容以时间戳格式显示
- 每条转写记录包含说话人和时间戳
- 支持离线转写（需安装 Whisper.cpp）

### AI 纪要
- 会议录音转写完成后，点击「AI 总结」生成结构化纪要
- 纪要包含：会议主题、时间、讨论要点、结论、待办

## 7. AI 助手

### 配置 AI 服务
1. 点击侧边栏「设置」
2. 在「AI 服务」区域配置 API Key
3. 支持 DeepSeek 和通义千问两种引擎

### AI 功能
- **润色文本**：选中文本后点击「润色文本」
- **扩写内容**：基于当前内容智能扩写
- **中译英/英译中**：一键翻译
- **生成摘要**：长文本自动生成摘要
- **提取待办**：从文本中自动识别并创建待办事项

## 8. 设置

### 通用设置
- **开机自启**：开关控制是否开机自动启动
- **系统托盘通知**：启用/禁用待办提醒通知

### 待办提醒
- **检查间隔**：设置待办到期检查的间隔时间（1-60分钟）

### AI 服务配置
- **AI 引擎**：选择 DeepSeek 或通义千问
- **API Key**：输入对应服务的 API Key（加密存储）
- **测试连接**：点击「测试连接」验证配置是否可用

## 9. 数据导出

### 导出笔记
- 单条笔记可导出为 Markdown/TXT 格式
- 批量导出保持标签和文件夹结构

### 导出录音
- 原始录音文件可导出为 WAV 格式

### 导出会议纪要
- AI 生成的会议纪要可复制或导出

### 数据存储位置
- 应用数据存储在 `~/.local/share/uos-shorthand/`
- 数据库文件：`uos-shorthand.db`
- 录音文件：`audio/` 目录

## 10. 常见问题

### Q: 全局快捷键 Alt+Space 不起作用？
A: 在 Wayland 环境下，部分桌面可能不支持全局快捷键。请尝试切换到 X11 模式，或在设置中检查快捷键是否被其他应用占用。

### Q: 如何迁移 deepin-voice-note 的数据？
A: 首次启动 UOS 速记时，如果检测到已安装 deepin-voice-note，会自动导入笔记数据。也可在设置中手动触发导入。

### Q: AI 功能无法使用？
A: 请确保在设置中配置了正确的 API Key。DeepSeek 和通义千问均提供免费额度，注册即可获取。

### Q: 如何备份数据？
A: 直接复制 `~/.local/share/uos-shorthand/` 目录即可完成数据备份。

### Q: 录音文件占用空间大吗？
A: WAV 格式录音约 10MB/分钟。建议使用后及时导出清理，或后续版本将支持 MP3 格式压缩。

### Q: 如何卸载 UOS 速记？
A: 在终端运行 `sudo apt remove uos-shorthand`，或通过应用商店卸载。
