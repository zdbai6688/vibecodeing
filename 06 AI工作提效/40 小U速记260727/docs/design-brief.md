# Design Brief: UOS 速记 — UI 视觉重构

> 生成时间: 2026-08-06
> 版本: 1.0
> 关联 Spec: docs/product-spec.md
> 触发: 用户验收反馈「当前 UI 太丑、太工业风」，要求重新设计

## 1. 设计理念

### 1.1 风格关键词
温暖、圆润、现代、清爽、轻量（去「工业风」：去掉生硬分隔线/直角/扁平灰块）

### 1.2 设计原则
1. **暖色分层代替硬线分隔**：用 `alternateBase` 卡片 + 少量留白代替 1px 竖线分区，层次靠背景色差而非边框。[从 Spec 推导：DTK6 桌面应用]
2. **圆角体系**：主面板 12px、卡片 10px、按钮 8px、徽章胶囊 999px，统一视觉节奏。
3. **主题自适应**：全部颜色取 DPalette / QSS `palette(...)` 角色，亮/暗色自动切换，不硬编码大面积底色。[从 Spec 推导：支持深色/浅色主题]
4. **克制的强调色**：主操作/选中态用系统强调色（palette highlight），语义色（逾期红/提醒橙）仅用于状态，不作为大面积背景。
5. **排版留白**：页面边距 16-20px，卡片内边距 12-16px，行高 ≥1.5，字号层级 H1 16 / 正文 13 / 辅助 11。

## 2. 色彩系统

### 2.1 主色（跟随系统强调色，自适应主题）
| 用途 | 取值 | 说明 |
|------|------|------|
| Primary | `palette(highlight)` | 主按钮、选中态、链接 |
| Primary-soft | `palette(highlight)` @ 10% alpha | hover/选中背景 |

### 2.2 中性色（DPalette 角色映射）
| 用途 | 亮色取值 | 暗色取值 | 说明 |
|------|----------|----------|------|
| 页面背景 | `palette(base)` | 同左（角色） | 主内容底 |
| 卡片/侧栏 | `palette(alternateBase)` | 同左（角色） | 侧栏、周报卡片、分组头 |
| 悬浮层 | `palette(window)` | 同左（角色） | 快速录入窗、弹窗 |
| 边框 | `palette(mid)` | 同左（角色） | 输入框、次要描边 |
| 文本主 | `palette(windowText)` | 同左（角色） | 正文 |
| 文本次 | `palette(placeholderText)` | 同左（角色） | 辅助说明 |
| 禁用 | `palette(disabled)` | 同左（角色） | 禁用态 |

## 5. 组件风格
### 5.1 按钮
- Primary（新建/保存）：强调色底 + 白色字 + 8px 圆角 + hover 加深；侧栏「＋ 新建笔记」36px 高。
- Secondary（次要操作）：透明底 + `palette(mid)` 1px 描边 + 8px 圆角 + hover 强调色描边。
- Ghost（工具栏/图标）：透明底，hover 浅灰圆角。

### 5.2 输入框
圆角 8px、1px `palette(mid)` 描边、focus 强调色描边、内边距 8-12px。

### 5.3 卡片（待办行、笔记项、周报格）
`palette(light)` 底 + 8-10px 圆角 + hover `palette(midlight)`；选中态强调色底白字。已完成待办行整体降饱和（灰底 + 删除线 + ✓ 前缀）。

### 5.4 导航（侧栏）
`alternateBase` 底 + 圆角导航项；选中项强调色软底 + 强调色文字 + 600 字重；徽章胶囊。

### 5.5 日历/周报
7 列网格卡片：日期数字 34px 圆点，今天强调色实心；每格显示「N 项」数量徽章 + tooltip 明细；周末列弱化底色。

## 6. 图标与插画
- 类型: emoji 轻量图标（延续现状，成本最低）+ 系统主题图标（document-new 等）
- 尺寸: 16-28px 工具栏，32-48px 空状态

## 7. 动效规范
- 微交互：hover 背景过渡 150ms ease-out；弹窗出现无动画（DTK 默认）。
- 不引入重动画（办公工具，克制）。

## 8. 暗色/亮色模式
全量走 DPalette 角色，QSS 使用 `palette(...)` 关键字；主题切换由 DTK 统一驱动，各组件在 `themeTypeChanged` 时刷新样式。
