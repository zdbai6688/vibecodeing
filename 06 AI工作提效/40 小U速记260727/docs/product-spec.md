## 1. 产品概述

### 1.1 产品定位

**UOS 速记** 是一款面向统信 UOS 桌面操作系统的**轻量级办公信息中枢**，聚焦「快速捕捉 → 智能整理 → 高效输出」闭环，整合笔记、待办、会议速记、AI 摘要四大核心能力，提供原生桌面体验。

### 1.2 目标用户

| 用户画像 | 核心场景 | 优先级 |
|---------|---------|--------|
| 政企办公人员 | 会议记录、待办跟踪、周报生成 | P0 |
| 开发者/文字工作者 | 速记灵感、Markdown笔记、语音输入 | P0 |
| 教育/培训场景 | 课堂录音+转写、AI总结 | P1 |
| 听障人士 | 实时语音转文字、会议字幕 | P2 |

### 1.3 核心差异点 vs 竞品

| 对比维度 | UOS 速记 | 麒麟速记 | deepin-voice-note | Windows 速记生态 | macOS 速记生态 |
|---------|---------|---------|-----------------|----------------|---------------|
| 平台 | UOS | 麒麟V11 | deepin | Windows | macOS |
| 离线ASR | ✅ Whisper.cpp | ❌（仅在线引擎） | ❌ | ✅（系统级） | ✅（Apple Neural） |
| 多引擎 | 插件化(在线+离线) | 百度/讯飞 | ❌ | 系统内置 | 系统内置 |
| AI摘要 | 可配置LLM API | 百川大模型 | ❌ | Copilot | 系统AI |
| 全局快捷键 | Alt+Space | Alt+Space | ❌ | Win+H | 全局快捷键 |
| 玲珑包发布 | ✅ | ❌（Kaiming） | ✅ | 不适用 | 不适用 |
| UOS原生DTK | ✅ | ❌ | ✅ | 不适用 | 不适用 |

### 2.2 功能详细说明

#### P0 — 基础能力（MVP，必须包含）

##### 2.2.1 笔记管理

| 功能 | 说明 | 验收标准 |
|------|------|---------|
| 创建笔记 | 支持富文本/Markdown双模式编辑 | 新建笔记默认保存，支持标题+正文 |
| 编辑笔记 | 富文本工具栏（粗体/斜体/下划线/标题/列表/图片） | 本地编辑实时保存，Ctrl+S 手动保存 |
| 删除笔记 | 移动到回收站，非永久删除 | 回收站内可恢复或永久删除 |
| 笔记列表 | 列表视图，显示标题、摘要、更新时间、标签 | 支持按更新时间倒序 |
| 搜索笔记 | 全文搜索（标题+正文） | 输入关键词实时过滤，支持拼音搜索 |
| 标签管理 | 创建/编辑/删除标签，笔记关联标签 | 支持多标签，标签筛选 |
| 文件夹管理 | 新建文件夹，笔记归类 | 支持拖拽移动，嵌套层级≤3级 |

##### 2.2.2 待办管理

| 功能 | 说明 | 验收标准 |
|------|------|---------|
| 创建待办 | 标题+截止日期+优先级（高/中/低） | 最小化输入，自然语言解析日期（如"明天"） |
| 完成待办 | 勾选标记完成 | 完成项移至已完成列表 |
| 待办列表 | 按优先级/截止日期排序 | 今日/本周/逾期分组视图 |
| 笔记⇔待办互转 | 笔记可标记为待办，待办可转为笔记 | 转换后保留原内容 |

##### 2.2.3 全局快速录入 (Alt+Space)

| 功能 | 说明 | 验收标准 |
|------|------|---------|
| 全局快捷键 | Alt+Space 唤起快速输入窗口 | 在任何应用中均可唤起 |
| 文本输入 | 快捷输入文字笔记 | 按 Enter 快速保存，Ctrl+Enter 打开详细编辑 |
| 语音输入 | 点击麦克风按钮开始录音转文字 | 转写结果实时显示在输入框 |
| 快速标签 | 通过 #标签 语法快速标记 | 自动识别标签并关联 |
| 快速待办 | 通过 !优先级 或 "今天" 等创建待办 | 自然语言识别 |

##### 2.2.4 系统集成

| 功能 | 说明 | 验收标准 |
|------|------|---------|
| 系统托盘 | 常驻系统托盘，右键菜单显示最近笔记 | 开机自启（可选），点击托盘打开主窗口 |
| 深色模式 | 跟随系统主题 | 自动切换深/浅色主题 |
| 数据存储 | SQLite 本地存储 | 数据安全，支持手动备份 |

#### P1 — 核心增强（首个正式版）

##### 2.2.5 会议速记

| 功能 | 说明 | 验收标准 |
|------|------|---------|
| 录音控制 | 开始/暂停/继续/停止录音 | 录音文件保存为本地文件 |
| 实时转写 | 录音同时转写为文字，实时显示 | 转写延迟<3秒，准确率>85%（中文） |
| 离线ASR | 基于 Whisper.cpp 的本地语音识别 | 无需网络，支持中文普通话 |
| 在线ASR | 可选百度/讯飞/阿里ASR（插件化） | 多引擎可切换，准确率>95% |
| 说话人识别 | 区分不同说话人并标注 | 需ASR引擎支持，标注为"说话人1/2/3" |
| 时间戳标记 | 转写文本附带时间戳 | 点击时间戳跳转到录音对应位置 |
| 会议历史 | 录音+转写+纪要统一管理 | 按日期分组，搜索支持 |

##### 2.2.6 AI 智能摘要

| 功能 | 说明 | 验收标准 |
|------|------|---------|
| 会议纪要生成 | AI自动生成结构化会议纪要 | 包含：主题、时间、参与人、讨论要点、结论 |
| 待办提取 | 从会议内容提取待办事项 | 自动识别"需要做/安排/跟进"等语义 |
| 文本总结 | 长文本一键总结要点 | 支持分段摘要，保留关键信息 |
| AI 配置 | 可配置 LLM API（DeepSeek/通义/百川等） | API Key 加密存储，支持自定义 Prompt |

#### P2 — 体验提升

##### 2.2.7 智能周报

| 功能 | 说明 | 验收标准 |
|------|------|---------|
| 周报生成 | 基于本周待办完成情况 AI 辅助生成 | 选中周 → 自动汇总已完成/未完成待办 |
| 自定义模板 | 支持自定义周报模板 | 模板 Markdown 格式 |

##### 2.2.8 导出与同步

| 功能 | 说明 | 验收标准 |
|------|------|---------|
| 笔记导出 | 支持 Markdown / TXT / PDF 导出 | 单条/批量导出 |
| 录音导出 | 原始录音文件导出 | 支持 MP3/WAV 格式 |

### 3.1 整体架构

```
┌──────────────────────────────────────────────────────────────────┐
```

### 3.2 技术选型

| 层次 | 技术方案 | 选型理由 |
|------|---------|---------|
| UI 框架 | DTK6 + Qt6 (Widgets) | UOS 原生体验，与系统主题一致，官方支持 |
| 开发语言 | C++17 | 性能优先，DTK6 原生绑定 |
| 数据存储 | SQLite | 无服务器，零配置，成熟稳定 |
| 富文本 | Qt6 WebEngine + TipTap 或 Markdown 编辑器 | 灵活支持富文本和 Markdown |
| 语音识别 | Whisper.cpp (离线) + 可选在线 ASR 插件 | 离线隐私优先，在线提高精度 |
| AI 大模型 | 可配置 API (DeepSeek/通义千问) | 灵活选择，无需自建模型 |
| 全局快捷键 | Qt6 平台抽象层 + xcb/Wayland 协议 | 跨平台兼容 |
| 音频采集 | GStreamer 或 PulseAudio 直采 | 成熟稳定，Linux 标准方案 |
| 打包 | 玲珑包 (linglong) + deb | 玲珑为 UOS 官方容器格式 |
| 构建系统 | CMake | 行业标准，DTK 官方推荐 |

### 3.3 数据模型

```sql
-- 笔记/待办数据表
CREATE TABLE notes_todos (
    id                    INTEGER PRIMARY KEY AUTOINCREMENT,
    title                 TEXT NOT NULL DEFAULT '',
    content               TEXT,                    -- Markdown 或 HTML 内容
    content_type          TEXT DEFAULT 'markdown',  -- markdown / richtext
    is_todo               INTEGER DEFAULT 0,       -- 0=笔记, 1=待办
    priority              INTEGER DEFAULT 0,       -- 0=无, 1=低, 2=中, 3=高
    is_completed          INTEGER DEFAULT 0,       -- 待办完成状态
    tag                   TEXT DEFAULT '',         -- 逗号分隔标签
    folder_id             INTEGER DEFAULT 0,       -- 文件夹ID
    creation_datetime     INTEGER NOT NULL,
    modification_datetime INTEGER NOT NULL,
    due_datetime          INTEGER DEFAULT 0,       -- 待办截止日期
    completed_datetime    INTEGER DEFAULT 0,       -- 完成时间
    is_deleted            INTEGER DEFAULT 0,       -- 软删除
    sync_status           INTEGER DEFAULT 0        -- 同步状态(预留)
);

-- 文件夹表
CREATE TABLE folders (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT NOT NULL,
    parent_id   INTEGER DEFAULT 0,
    sort_order  INTEGER DEFAULT 0,
    created_at  INTEGER NOT NULL
);

-- 会议记录表
CREATE TABLE meetings (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    title           TEXT NOT NULL DEFAULT '',
    started_at      INTEGER NOT NULL,
    ended_at        INTEGER DEFAULT 0,
    duration_secs   INTEGER DEFAULT 0,
    audio_file_path TEXT DEFAULT '',
    ai_summary      TEXT DEFAULT '',
    manual_notes    TEXT DEFAULT '',
    status          TEXT DEFAULT 'recording',  -- recording/completed/processing
    created_at      INTEGER NOT NULL
);

-- 会议转写内容表
CREATE TABLE meeting_transcripts (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    meeting_id  INTEGER NOT NULL,
    sequence    INTEGER NOT NULL,           -- 消息序号
    speaker     TEXT DEFAULT '',            -- 说话人
    text        TEXT NOT NULL,              -- 转写文本
    timestamp_ms INTEGER NOT NULL,          -- 相对录音起始的毫秒偏移
    created_at  INTEGER NOT NULL,
    FOREIGN KEY (meeting_id) REFERENCES meetings(id)
);

-- 标签表
CREATE TABLE tags (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT NOT NULL UNIQUE,
    color       TEXT DEFAULT '#1890FF',
    created_at  INTEGER NOT NULL
);

-- 设置表
CREATE TABLE settings (
    key   TEXT PRIMARY KEY,
    value TEXT NOT NULL
);
```

### 7.2 差异化优势

1. **离线ASR (Whisper.cpp)** — 政企客户的隐私刚需，不依赖外网
2. **Markdown 原生支持** — 开发者友好，非 OneNote/Apple Notes 的强项
3. **玲珑包发布** — 跨发行版兼容，UOS 应用商店权威渠道
4. **开放 AI 架构** — 可配置任意 LLM API，不被单一厂商绑定
5. **UOS 原生 DTK 体验** — 与系统主题深度一致，性能优于 Electron

## 8. 风险评估

| 风险 | 等级 | 应对策略 |
|------|------|---------|
| Whisper.cpp 模型大小 (1-3GB) | 中 | 首次使用时下载，进度提示；提供纯在线模式选项 |
| 全局快捷键在 Wayland 下兼容 | 高 | 使用 portal 协议，降级方案为 D-Bus 全局快捷键 |
| ASR 实时转写延迟 | 中 | 流式处理，分段显示，优化 Whisper 模型大小选择 |
| LLM API 调用成本 | 低 | 支持本地小模型 (如 ChatGLM.cpp) 作为备选 |
| 与 deepin-voice-note 关系 | 中 | 基于其代码库做增量开发，保持数据兼容性 |
| 政企客户信创要求 | 中 | 纯离线模式，数据不出本机，适配国产 CPU |
