# UOS 速记 v1.2.0 "速记·全能" — Release Notes

> 发布日期：2026-08-06
> 版本号：v1.2.0
> 状态：v1.2 迭代（Phase 6）完成，5 项功能增强收口（commit 644c7ee / fd46ec5，分支 feature/phase2-utility-tools）

---

## 概述

UOS 速记 v1.2.0 在 v1.1.0 基础上完成「数据安全」「个性化」「性能」三大主题增强：一键数据备份/恢复、标签颜色自定义、周报模板自定义、启动提速、说话人识别。至此 remaining-work.md 全部 25 项完成。

## 新功能

### 数据备份 / 恢复（IDE-214，V2-T5）
- 一键备份全部数据（SQLite 数据库）到用户指定目录，文件带时间戳 `uos-shorthand-backup-<yyyyMMdd-hhmmss>.db`
- 备份附带 SHA-256 校验文件，恢复前自动校验，防止损坏文件覆盖数据
- 恢复前自动把当前数据保留为 `.pre-restore-<时间戳>` 备份，恢复失败自动回滚
- 设置页新增「数据备份」页：一键备份 / 从备份恢复（含二次确认）

### 标签颜色自定义（IDE-212，V2-T3）
- 设置页新增「标签颜色」页：为每个标签选择颜色，立即持久化
- 侧栏标签列表前置彩色圆点徽章
- 笔记列表标签、待办卡片徽章按标签色显示

### 周报模板自定义（IDE-214，V2-T4）
- 周报支持自定义 Markdown 模板，占位符：`{date_range}` `{summary}` `{completed}` `{pending}` `{schedule}` `{tag_stats}` `{note_count}` `{generated_at}`
- 设置页「周报模板」页可编辑 / 一键恢复默认模板；模板持久化
- 周报页「AI 生成周报 / 预览 / 导出」均按自定义模板输出

### 启动速度优化（IDE-211，V2-T2）
- 会议页 / 周报页懒加载：首次进入才构造真实控件
- 实测首窗显示 2210ms → 1522ms（约 -31%）

### 说话人识别（IDE-210，V2-T1）
- 会议转写区分发言人（Whisper 声学特征聚类）
- AI 会议纪要按发言人组织要点

## 系统要求

- 操作系统：统信 UOS 1070 及以上
- 架构：amd64
- 内存：建议 2GB+
- 磁盘：100MB+

## 已知问题

1. **Wayland 全局快捷键**：部分 Wayland 桌面环境下快捷键可能受限，建议使用 X11 模式
2. **离线语音转写**：Whisper 模型文件需就位于应用数据目录，首次使用自动复制
3. **AI 服务**：需要自行配置 API Key（DeepSeek/通义千问均提供免费额度）

## 更新日志

### v1.2.0 (2026-08-06)
- 数据备份/恢复（一键 SQLite + SHA-256 校验）
- 标签颜色自定义（设置页选色 + 全端按色显示）

- 启动速度优化（会议/周报页懒加载，-31%）
- 说话人识别（转写分发言人 + AI 纪要按发言人组织）

## UOS 速记 v1.0.0 "速记·启程" — Release Notes

> 发布日期：2026-07-27
> 版本号：v1.0.0
> 状态：34/34 个规划 Issue 全部完成

---

## 概述

UOS 速记 v1.0.0 是统信 UOS 原生的办公信息中枢首个正式版本，集笔记管理、待办跟踪、语音速记、AI 会议助手于一体。通过 Alt+Shift+S 全局快捷键随时捕捉灵感，支持 Markdown 笔记、语音录音、离线/在线语音转写、AI 智能摘要。

## 新功能

### 笔记管理
- Markdown 编辑器，支持语法高亮和预览模式
- 工具栏：B/I/U/H1/H2/H3/列表/代码块/链接
- 标签分类，全文搜索
- 文件夹管理，回收站支持

### 待办管理
- 待办看板视图：今日/本周/逾期/已完成四组自动分组
- 优先级（高/中/低），截止日期
- 笔记⇔待办一键互转
- 系统托盘到期提醒

### 快速捕捉
- Alt+Space 全局快捷键快速录入
- `#标签` 语法自动识别标签
- `!高/中/低` 优先级语法
- 语音输入和截图录入

### 会议助手
- 会议录音（GStreamer 引擎，WAV 格式输出）
- 会议记录管理（列表/详情/搜索）
- 转写内容时间戳标注
- AI 会议纪要生成

### AI 助手
- 多引擎支持：DeepSeek / 通义千问
- 文本润色、扩写、翻译（中↔英）
- 长文本摘要生成
- 待办自动提取

### 系统集成
- 系统托盘常驻，快捷菜单
- 开机自启（可选）
- 深色/浅色主题跟随
- 玲珑包发布（如意玲珑）
- 数据 100% 本地存储
