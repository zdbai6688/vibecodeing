## 概述

UOS 速记 v1.0.0 是统信 UOS 原生的办公信息中枢首个正式版本，集笔记管理、待办跟踪、语音速记、AI 会议助手于一体。通过 Alt+Shift+S 全局快捷键随时捕捉灵感，支持 Markdown 笔记、语音录音、离线/在线语音转写、AI 智能摘要。

## 新功能

### 笔记管理
- Markdown 编辑器，支持语法高亮和预览模式
- 工具栏：B/I/U/H1/H2/H3/列表/代码块/链接
- 标签分类，全文搜索
- 文件夹管理，回收站支持

### 待办管理
- 待办看板视图：今日/本周/逾期/已完成四组自动分组
- 优先级（高/中/低），截止日期
- 笔记⇔待办一键互转
- 系统托盘到期提醒

### 快速捕捉
- Alt+Space 全局快捷键快速录入
- `#标签` 语法自动识别标签
- `!高/中/低` 优先级语法
- 语音输入和截图录入

### 会议助手
- 会议录音（GStreamer 引擎，WAV 格式输出）
- 会议记录管理（列表/详情/搜索）
- 转写内容时间戳标注
- AI 会议纪要生成

### AI 助手
- 多引擎支持：DeepSeek / 通义千问
- 文本润色、扩写、翻译（中↔英）
- 长文本摘要生成
- 待办自动提取

### 系统集成
- 系统托盘常驻，快捷菜单
- 开机自启（可选）
- 深色/浅色主题跟随
- 玲珑包发布（如意玲珑）
- 数据 100% 本地存储

## 安装方式

### 方式一：UOS 应用商店
搜索 "UOS速记" 并点击安装。

### 方式二：玲珑包
```bash
ll-cli install uos-shorthand
```

### 方式三：deb 包
```bash
sudo apt install ./uos-shorthand_1.0.0-1_amd64.deb
```

## 系统要求

- 操作系统：统信 UOS 1070 及以上
- 架构：amd64
- 内存：建议 2GB+
- 磁盘：100MB+

## 已知问题

1. **Wayland 全局快捷键**：部分 Wayland 桌面环境下 Alt+Space 快捷键可能受限，建议使用 X11 模式
2. **离线语音转写**：Whisper.cpp 集成需额外安装，v1.0 默认使用在线模式
3. **AI 服务**：需要自行配置 API Key（DeepSeek/通义千问均提供免费额度）
